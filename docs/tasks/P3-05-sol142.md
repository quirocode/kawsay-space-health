## The story (Mars transit, day 142 of 180, one-way delay 14 min)
1. Days 1–135: a disciplined crew member. Exercise ~80–95 min/day, water ~2.3–2.7 L, sleep ~6.8–7.4 h, vitals normal, mood 3–5.
2. **Days 136–141: exercise incomplete** (45–60 min/day: below the 90 min target, never below 45 so it reads "Watch", not "Act"). Water drifts down to ~1.6–1.8 L.
3. Days 140 and 141: short sleep (4.4–4.8 h). Day 142 (last night): 6.4 h.
4. **Day 142, 07:40 morning check: everything green today.** BP 118/76, HR 64, temp 36.7, glucose 92, sleep 6.4, mood 4, no symptoms, SpO₂ 97, cabin CO₂ 2.4.
5. **Day 142, 13:10:** headache 4/5 reported; cabin CO₂ 4.1 mmHg (sensor).
6. **Day 142, 13:45 (verification beat, NOT in the initial history):** headache 2/5, cabin CO₂ 2.6.
7. Weekly `strength_self_pct` on days 7, 14, … 140: slowly declining from 99 to about 91.

import type { MissionContext, Reading } from '../domain/types';

/** Mulberry32 — copy exactly. */
export function mulberry32(seed: number): () => number {
  return function () {
    let t = (seed += 0x6d2b79f5);
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

### Reading rules
- Daily readings at 07:40 of each day for: `bp_systolic`, `bp_diastolic`, `heart_rate`, `glucose`, `body_temp`, `sleep_hours`, `mood`, `spo2`, `cabin_co2`. Daily at 21:00 for `exercise_min` and `water_ml` (the day's totals) — **except day 142, which has no 21:00 readings yet** (it's morning).
- Symptoms (`headache_score`, `symptom_*`): record `headache_score = 1` and all symptoms `0` at the 07:40 check of each day, except use the PRNG to add 2–3 harmless one-off events across days 1–135 (e.g. a headache 2/5, a dizziness on day 3: space motion sickness). Never on days 136–142 except the story beats.
- `origin`: `'sensor_sim'` for `cabin_co2`, `spo2`, `heart_rate`; `'manual'` otherwise.
- `phase`: `'cruise'` for all readings.
- Noise: use the PRNG with small Gaussian-like noise (sum of 3 uniforms) around these means — BP 117/76 (±4), HR 63 (±3), glucose 92 (±6), temp 36.7 (±0.15), SpO₂ 97 (±0.7), CO₂ 2.3 (±0.3, never ≥ 3.0 before day 142 13:10). Round: BP/HR/glucose to integers, temp 1 decimal, SpO₂ integer, CO₂ 1 decimal, sleep 1 decimal, water to 50 mL, exercise to 5 min.
- Day 142 07:40 values are **exactly** those in step 4 (not noisy).
- `defaultPlan` = `{ exerciseMinPerDay: 90, exerciseDaysPerWeek: 7, waterMlPerDay: 2500, sleepHours: 7 }`.
